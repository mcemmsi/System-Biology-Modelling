# System-Biology-Modelling

This GITHUB contains the Supplementary Files for our final project on "Reconstruction of the metabolic model iSR432 of Clostridium
thermocellum"

Supplementary File 1 (Model) contains the recreated iSR432 model in .xml format.

Supplementary File 2 (Code) contains the AI-generated code we used to generate the SBML model from the .txt file from the original paper's additional data.
